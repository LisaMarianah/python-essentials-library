# Project Description

This project is a console-based Library Management System developed in Python. It allows users to manage books and members, borrow and return books, search the catalogue, and generate library reports.

# How to Run

1. Open the project in Visual Studio Code, PyCharm, or IDLE.
2. Open the file containing the Library Management System code.
3. Run the Python file.
4. The main menu will appear in the terminal.
5. Enter a number between 1 and 8 to choose an option:
  1 – Add a book
  2 – Register a member
  3 – Borrow a book
  4 – Return a book
  5 – Search the catalogue
  6 – View a member summary
  7 – Generate the library report
  8 – Exit the program
6. Follow the prompts to enter book and member information.
7. Continue using the menu until you choose 8 to exit.
